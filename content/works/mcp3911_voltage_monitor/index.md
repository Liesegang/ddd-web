## これは何？

この測定器を作った目的は、IoTデバイスの消費電力を測ることでした。
無線送信時のピーク、センサーを読む時間、スリープ中のわずかな電流は、テスターに表示される一つの数字だけでは区別できません。
電源電圧とシャント抵抗の電圧降下を同じ時刻に記録し、動作ごとの電力をあとから確かめる必要がありました。

**MCP3911 2チャンネル電圧／電流測定器**は、二つの端子間電圧を同時に測り、手元のOLEDとWebブラウザの両方で確認できる50 mm角の測定基板です。
USBを外しても1セルLiPoで動かせるため、PCの前を離れて測ることもできます。

## 二つの使い方

| モード | できること |
| --- | --- |
| ハンディ計測 | OLEDに2チャンネルの現在値を表示し、PCなしで確認する |
| Web計測 | USBでPCまたはAndroid端末へ接続し、波形の記録と解析を行う |

基板だけで値を見たいときに、PCを立ち上げる必要はありません。
反対に、変化の過程を残したいときは、ブラウザがロガーと解析器になります。

専用アプリのインストールは不要です。
デスクトップ版ChromeまたはEdgeではWeb Serial、Android版ChromeではFT234XD用のWebUSB接続を使います。

[Webダッシュボードを開く](https://liesegang.github.io/mcp3911-voltage-monitor/)

## 2チャンネルを同時に測る理由

MCP3911には独立した2基のADCがあり、Channel 0とChannel 1を同じタイミングで変換します。
マルチプレクサで入力を順番に切り替える方式ではないため、二つの波形の位相や立ち上がりを同じ時間軸で比べられます。

たとえばIoTデバイスの消費電力を調べるなら、一方で負荷にかかる電圧を測り、もう一方でシャント抵抗の電圧降下を測ります。
シャント抵抗が0.1 Ωなら、ダッシュボードの演算式は次のようになります。

```text
電流: channel1 / 0.1
瞬時電力: channel0 * channel1 / 0.1
```

瞬時電力を時間で積分すれば、選択した区間の消費電力量まで求められます。
無線送信、センサー読み出し、スリープという動作ごとに、「いつ、どれだけ使ったか」を記録できます。

## Webダッシュボード

{{< img800x src="mcp3911/dashboard.png" alt="2チャンネルの波形と演算結果を表示したWebダッシュボード" >}}

ダッシュボードには次の機能を実装しました。

- 2チャンネルの時間波形表示
- 最大値、最小値、平均値、Peak-to-peakの集計
- 最大4096点を使ったFFT解析
- 任意の演算式と数値積分
- 表示範囲または選択範囲のCSV保存
- 保存したCSVの再読み込みと再解析

受信処理と描画処理は分離し、ADCのサンプルを取りこぼさずにグラフ更新を最大30 Hzへ抑えました。
パネルは並べ替え、分割、タブ化、サイズ変更ができ、配置はブラウザに保存されます。

## 主な仕様

| 項目 | 仕様 |
| --- | --- |
| ADC | MCP3911、2チャンネル同時変換 |
| ADC出力 | 24-bit符号付き整数 |
| 入力範囲 | 約−0.6〜0.6 V |
| MCLK / OSR | 16 MHz / 4096 |
| 変換速度 | 976.5625 samples/s |
| MCU | STM32C011F6 |
| USBシリアル | FT234XD、1,500,000 baud |
| 表示 | 128 × 64 OLED、I2C |
| 基板 | 50 mm × 50 mm、2層 |

この入力は高電圧測定用ではありません。
4本の測定端子は、いずれも基板のGNDに対して−1〜1 Vの範囲に収める必要があり、測定対象との絶縁もありません。

## ハードウェアからWebまで公開

EAGLEの回路図と基板データ、STM32CubeIDE用ファームウェア、ReactとViteで作ったWebダッシュボードをGitHubで公開しています。
組み立て方、通信フレーム、入力条件、ブラウザごとの対応状況も同じリポジトリにまとめました。

- [GitHubリポジトリ](https://github.com/Liesegang/mcp3911-voltage-monitor)
- [制作日誌：ポケット測定器を基板から作る](/posts/mcp3911-voltage-monitor-development/)

小さなOLEDに二つの数字が並ぶだけでも、机から離れた測定はずいぶん楽になります。
USBを挿した瞬間、その同じ基板が波形、周波数、電力まで追える測定器へ切り替わります。
